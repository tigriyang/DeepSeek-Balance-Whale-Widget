# 迭代记录

这个程序不是一次写成的。下面按时间顺序记下每一轮**为什么改**、**踩了什么坑**，
而不是只列最终结果——因为大部分设计决定都是被具体的失败推着走出来的。

---

## 一、缘起：从网页插件到独立程序

最初的目标只是「装一个推理强度滑块插件和余额显示插件」。
余额显示那一半后来演变成：**不要网页里的浮层，要一个真正独立的桌面程序**。

于是有了 WhaleFloat：Swift + AppKit，打包成 .app，
无 Dock 图标（LSUIElement），由 launchd 守护。
它不依赖 DSH 运行时——余额直连 api.deepseek.com，峰谷价纯本地算，
只有「每轮消耗」和「等用户回答」这两类数据需要 DSH 侧配合。

**为什么不用 Python + pyobjc**：做过一版，能跑，但常驻进程重、
依赖 Python 环境、功能只能逐个补。改成 Swift 原生后启动快、内存小、
能打包成标准 .app、由 launchd 管理。

## 二、反复推翻的几个决定

### 1. 气泡从哪来：抠图 → 分层

**错误做法**：角色素材 DSniang02.png 自带一个手绘对话气泡，
于是想把气泡「抠掉」生成一张无泡版，显示/隐藏时切换底图。

**为什么行不通**：气泡的描边和角色的**呆毛**在像素上紧邻甚至相连：

```
y=462:  (263-649)泡泡   (664-686)呆毛根   (779-816)呆毛
y=450:  (234-808)       ← 连成一段，无法分离
```

试过 6 种切法（形态学膨胀、逐行边界、段级清除、x 封顶……），
**每种的瑕疵只是换个位置**：margin 大则切掉呆毛根，margin 小则描边残留。
这是几何上的无解，不是调参不够。

**正确做法**：网页版原作本来就是**分层**的——角色图是纯角色，
气泡由 SVG 单独绘制。照做即可：角色层用纯角色素材，
气泡层用 NSBezierPath 画椭圆 + 三个递减圆点。
显示/隐藏只控制气泡层，问题整体消失。

### 2. 材质：两种 API，一旧一新

背景一度是纯白。真正的原因有两个：

1. **SDK 版本**。Package.swift 里写的是 `.macOS(.v13)`，
   编出来的二进制 LC_BUILD_VERSION 里 `sdk = 13.0`，
   系统据此认为这是老 app，一律按**兼容模式**渲染。
   改成 `"26.0"` 后才用上 Liquid Glass。
2. **API 世代**。NSVisualEffectView 是 Big Sur 时代的旧 API，
   在 Liquid Glass 下会被降级。macOS 26 引入了新的
   **NSGlassEffectView**——这才是正主，而且 cornerRadius 可控。

### 3. 菜单容器：NSMenu → NSPopover → 自绘 NSPanel

| 方案 | 圆角 | 点外面自动关 |
|---|---|---|
| NSMenu | 系统 | ✓ |
| NSPopover | 系统定，改不了 | ✓（.transient）|
| 自绘 NSPanel | **可控** | ✗ 需自己实现 |

中间在「圆角可控」和「关闭行为」之间来回换过好几次。
最后停在**自绘 + 不监听全局鼠标**：关菜单靠「再点一次浮窗」或「点菜单项」，
**不需要辅助功能权限**——这是权衡后认为副作用最小的方案。

## 三、踩过的坑（按教训记）

### 「同一个量写两遍，早晚不一致」

菜单上下留白怎么调都不对称。最后量数据才发现：

```swift
computeHeight()  用 Self.dividerHeight = 11 算高度
divider()        却硬编码 heightAnchor = 7
```

3 条分隔线 × 差 4 = **12pt**，全堆在底部。
我一直在调「外在留白」，而问题在「内在差额」。

### 「改完必须核对产物」

有整整几轮改动「没生效」，原因是跑完构建命令就以为成功了，
实际编译失败 / 或忘了重启。后来固定在每次构建后核对**二进制的时间戳**。

### 「测试要珍惜副作用」

验证「启动 DSH GUI」时反复触发启动器，结果浏览器页面一个接一个冒出来
——因为启动器每次调用都会 `open` 一次 URL。**测试是有副作用的**。

### 「pkill 在 macOS 上不可靠」

macOS 的进程名截断到 16 字符，dsh-launcher.sh、dsh web 这类
根本匹配不到。得用 `ps -axo pid=,command=` 拿完整命令行再筛。

### 「launchd 的 KeepAlive: true 是『关不掉』」

不是「崩溃自愈」。想只在崩溃时拉起，要用：

```xml
<key>KeepAlive</key>
<dict><key>SuccessfulExit</key><false/></dict>
```

## 四、最终产物

```
WhaleFloat.app          独立桌面程序，无 Dock 图标，launchd 守护
├── dsh-wait-state      DSH 插件：等回答/授权时上报状态
└── dsh-turn-usage      DSH 插件：采集每轮消耗
```

后两个插件随 app 发布，首次运行时程序会引导安装。

### 功能

- **余额气泡**：单击鲸鱼，显示余额 / 今日已用 / 峰谷字 / 时间
- **每轮消耗**：一轮对话结束自动冒泡
- **等待提示**：DSH 等用户回答或授权时，持久显示（不自动消失）
- **摸摸头**：点击时角色压扁拉宽（scaleY .86 / scaleX 1.07）+ 音效
- **分析页**：多轮消耗折线图 + 三个状态灯 + 一键重启服务
- **高级设置**：紧凑的行式控件
- **记账**：逐轮明细、导入自定义角色

### 特点

- **不依赖 DSH 运行时**：余额直连 API，峰谷价本地算
- **零系统权限**：不用辅助功能、不用自动化、不用屏幕录制
- **数据同源**：与网页版鲸鱼的账本格式兼容，历史数据无损
